# Flight Fare Prediction ✈️

A Machine Learning project that predicts airline ticket prices using Random Forest Regression.

### Technologies Used
- Python
- Pandas & NumPy
- Matplotlib & Seaborn
- Scikit-learn

### Project Steps
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Random Forest Model Training
- Model Evaluation

### Model Results

| Metric | Score |
|---|---:|
| MAE | 1077.35 |
| RMSE | 2786.68 |
| R² Score | 98.49% |

### Algorithm
Random Forest Regressor

### Dataset
300,153 flight records containing airline, route, class, duration and other flight details.

### Status
Completed – Model training and evaluation.
